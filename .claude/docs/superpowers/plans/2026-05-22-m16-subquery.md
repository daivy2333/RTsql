# M16 子查询支持 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 全面支持 SQL 子查询（WHERE IN/EXISTS、NOT IN/NOT EXISTS、SELECT 标量子查询、FROM 派生表、相关子查询），通过混合策略实现（SemiJoin 反嵌套 + Volcano 子查询节点）。

**Architecture:** WHERE 子查询反嵌套为 SemiJoin/AntiJoin（hash-based O(N+M)），SELECT 标量子查询保留 SubqueryEval Volcano 节点，FROM 子查询使用 DerivedScan 节点。相关子查询通过 CorrelatedParam 机制传递外层列值。

**Tech Stack:** Rust, Tokio async, sqlparser-rs, existing Volcano executor framework
